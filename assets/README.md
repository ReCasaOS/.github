# ReCasaOS brand assets

The approved server mark and custom wordmark, in native SVG paths. Lime `#BEF500`, charcoal `#151515`, warm white `#F7F6F0`.

Use `recasaos-banner.svg` on README pages, `recasaos-logo.svg` on dark backgrounds, `recasaos-logo-dark.svg` on light backgrounds, and the tile icon for app icons and avatars. The icon without a tile is transparent.
